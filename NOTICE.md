# Notice / 公告

This repository contains source code, local-agent instructions, a small web UI, tests, and example configuration for an invoice reimbursement assistant.

本仓库包含发票报销助手的源代码、本地智能体说明、小型 Web 界面、测试和示例配置。

## Data Notice / 数据公告

- No real invoices, reimbursement workbooks, company records, salary records, or runtime ledgers are intentionally included.
- Runtime files such as `data/`, invoice folders, generated Excel workbooks, generated PDFs, image invoices, and local config files are ignored by git.
- Users are responsible for checking their own repository state before publishing changes.

- 本仓库不应包含真实发票、报销表、企业记录、工资记录或运行台账。
- `data/`、发票目录、生成的 Excel、生成的 PDF、发票图片和本地配置文件默认被 git 忽略。
- 用户在发布变更前，应自行复核仓库状态。

本仓库暂未包含明确开源许可证。仓库对外可见并不自动授予超出 GitHub 托管所允许范围的复用权利。

## Financial Review Notice / 财务复核公告

The assistant is an operational tool. OCR and model extraction can be wrong, incomplete, or ambiguous. Human review remains required before filing, payment, tax treatment, accounting entry, or audit use.

本助手是操作辅助工具。OCR 和模型抽取可能错误、不完整或存在歧义。用于报销归档、付款、税务处理、会计入账或审计前，仍必须人工复核。
