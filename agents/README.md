# Agents and Skills / 智能体与技能

This directory contains reusable workflow assets for maintaining the finance reimbursement assistant.

本目录包含维护财务报销助手时可复用的工作流资产。

- `skills/github-submit-assistant`: repository-local submit assistant for public-release checks, privacy scans, validation, commits, and pushes.
  仓库内提交助手，用于公开发布检查、隐私扫描、验证、本地提交和推送。

The reimbursement runtime skills used by the assistant live in the root `skills/` directory.

报销助手运行时使用的技能位于仓库根目录的 `skills/` 目录。
