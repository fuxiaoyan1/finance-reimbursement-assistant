# 发票解读 Skill

## 输入

- 原始文件名
- PDF 文字层或 OCR 文本
- 本地规则解析候选

## 输出

单张发票或附件的结构化字段：

- 是否正式发票
- 是否报销附件
- 发票代码
- 发票编号
- 开票日期
- 销售方
- 购买方
- 不含税金额
- 税额
- 价税合计
- 报销种类
- 是否计入汇总
- 置信度
- 复核备注

## 规则

- 中国数电票常见 20 位号码可作为发票编号。
- “价税合计（小写）”“小写”“总计”“Total”“Grand Total”“Amount Due”优先作为 `total_amount`。
- 如果人民币符号和数字在 PDF 文本中被拆行，不要跨过发票号码、纳税人识别号、下载次数去抓金额。
- 行程单、Trip Table、订单、支付截图不是正式发票；可以保留为附件，但 `include_in_total=false`。
- 当同一文件既有行程单又有发票时，以正式发票为准计入；单独行程单不计入。
- 字段冲突时保守处理，写入复核备注。

## 分类

- 机票、燃油附加费、民航发展基金、滴滴、出租车、高铁、停车、高速、加油归入交通费。
- 酒店、住宿、宾馆、旅店归入住宿费。
- 餐厅、餐饮、食品、咖啡、外卖归入餐饮费。
- 无法判断时使用待分类。
